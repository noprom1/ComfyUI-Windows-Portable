Папка переводов интерфейса ComfyUI
===================================

Как добавить перевод
--------------------
1. Создайте подпапку с кодом языка, например:
       tl\ru        — русский
       tl\de        — немецкий
       tl\fr        — французский
2. Положите туда один или несколько JSON-файлов:

       main.json      — тексты интерфейса (меню, диалоги, кнопки)
       nodeDefs.json  — названия/описания нод и их входов
       commands.json  — названия команд (меню команд, хоткеи)
       settings.json  — названия и описания настроек

3. Перезапустите ComfyUI. Перевод подхватывается автоматически и
   накладывается ПОВЕРХ встроенного перевода того же языка
   (совпадающие ключи берутся из tl\).

Важно: код языка должен совпадать с одним из языков, встроенных в
интерфейс ComfyUI (список ниже), иначе язык не появится в выборе
языка (Settings -> Language). Китайский (zh, zh-TW) из сборки вырезан.

Доступные коды языков в этой сборке:
    en, ru, ja, ko, fr, es, ar, tr, pt-BR, fa, he, it

Выбор языка: Settings (шестерёнка) -> пункт "Language" (Comfy.Locale).
По умолчанию установлен английский.

Как это работает
----------------
Узел ComfyUI\custom_nodes\tl_bridge при старте создаёт ссылку
    custom_nodes\tl_bridge\locales  ->  <корень сборки>\tl
ComfyUI собирает переводы всех custom_nodes из папок locales\<lang>\ и
отдаёт их фронтенду через /i18n. Ссылка пересоздаётся автоматически,
поэтому сборку можно перемещать по дискам/компьютерам.

Формат файлов — как в официальной документации ComfyUI по переводам
custom nodes. Пример живого перевода лежит в tl\ru\nodeDefs.json:
он переименовывает ноду KSampler — если после выбора русского языка
и перезапуска вы видите это имя на ноде, механизм работает.

Свой перевод удобно делать так: возьмите готовый перевод нужного
языка из сообщества ComfyUI (файлы той же структуры), положите в
tl\<lang>\ и правьте только те строки, которые хотите изменить.
